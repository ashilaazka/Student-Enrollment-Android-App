# Student Enrollment Android App

## Description
This is a simple Android application developed for the Mobile App Development midterm exam. It helps manage student enrollment data.

## Features
- Add student data
- View student records
- Edit student information
- Delete student records
- Store data using SQLite

## Technologies
- Java
- XML
- SQLite
- Android Studio

## Purpose
This application was developed as part of the Mobile App Development course.
